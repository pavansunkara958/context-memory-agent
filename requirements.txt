# Core — the whole lab runs on these three.
#
# Deliberately minimal. Everything optional lives in requirements-optional.txt
# and is guarded by a fallback in the code, because the two obvious extras
# (chromadb, sentence-transformers) both pull native wheels that do not exist
# for every Python and platform:
#
#   chromadb              -> onnxruntime, no cp314 wheel
#   sentence-transformers -> torch, no macOS x86_64 wheel after 2.2
#
# A pinned dependency that cannot install on the grader's machine is worse than
# an optional one that degrades. Install these, run the suite, then add the
# extras if your platform supports them.
